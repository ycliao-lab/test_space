# 🌍 世界天氣查詢應用

一個簡單易用的天氣查詢網頁應用，可以查詢世界各地的實時天氣信息。

## 功能特性

✨ **實時天氣數據** - 使用 Open-Meteo API 獲取最新天氣信息
🔍 **全球城市查詢** - 支援搜尋世界各地的城市
📊 **詳細天氣信息** - 顯示溫度、體感溫度、濕度、風速、氣壓等
🌟 **快速熱門城市** - 一鍵查詢熱門城市天氣
📱 **響應式設計** - 支援桌面電腦和行動設備

## 快速開始

### 方式 1：直接打開 HTML 文件（推薦新手）

在 VS Code 中右鍵點擊 `index.html` 文件，選擇「用瀏覽器打開」，就能立即使用！

### 方式 2：使用 Flask 服務器運行

1. **安裝依賴**
   ```bash
   pip install -r requirements.txt
   ```

2. **運行應用**
   ```bash
   python main.py
   ```

3. **打開瀏覽器**
   在瀏覽器中訪問：http://localhost:5000

## 使用指南

1. **搜尋城市天氣**
   - 在搜尋框中輸入城市名稱（支援中英文）
   - 點擊「搜尋」按鈕或按 Enter 鍵

2. **快速查詢**
   - 點擊下方「熱門城市」按鈕快速查詢常見城市天氣

3. **查看天氣信息**
   - 溫度：當前氣溫
   - 體感溫度：考慮風速的實際體感溫度
   - 濕度：空氣濕度百分比
   - 風速：風的速度（單位：km/h）
   - 氣壓：大氣壓力（單位：hPa）

## 技術棧

- **前端**：HTML5, CSS3, Vanilla JavaScript
- **後端**（可選）：Python Flask
- **API**：
  - Open-Meteo（天氣數據）
  - OpenStreetMap Nominatim（地理位置）

## 文件說明

- `index.html` - 主要的網頁應用（可獨立運行）
- `main.py` - Flask 服務器（可選）
- `requirements.txt` - Python 依賴列表

## 注意事項

✅ **無需 API Key** - 使用免費開源 API
✅ **隱私保護** - 所有查詢在客戶端進行，數據不會保存
✅ **跨瀏覽器兼容** - 支援所有現代瀏覽器

## 故障排除

**問題：顯示「找不到該城市」**
- 檢查城市拼寫是否正確
- 嘗試用英文輸入城市名稱

**問題：無法獲取天氣信息**
- 檢查網際網路連接
- 某些城市的小寫版本可能更容易被識別
